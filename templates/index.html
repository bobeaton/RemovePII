This page will redact PII from an uploaded text or PDF file using the {{ MODEL_NAME }} model. See https://huggingface.co/{{ MODEL_NAME }}. Every detected item (names, emails, phone numbers, addresses, URLs, dates, account numbers, credentials) is replaced with a placeholder. PDF pages with no real text layer (scanned or flattened-to-image pages) are OCR'd first, so PII baked into an image can still be found and redacted.

OCR review checkpoint

For a scanned/image-only PDF, this converts each image-only page into real, searchable text at roughly its original layout -- no redaction happens here. Nothing is guaranteed found or fixed automatically; it exists so you can open the result in a normal PDF viewer, search it or read it to check what OCR actually saw, and even hand-correct misreads, before running it through Redact above as an ordinary PDF.

API instructions

  • POST /api/v1/redact/ with multipart/form-data: file, outputFormat (pdf|text), customTerms (optional, one exact string per line)
  • POST /api/v1/ocr-flatten/ with multipart/form-data: file (.pdf) -- OCR review checkpoint, does not redact
  • GET /api/v1/download/<jobId> -- one-time-use download link returned by either of the above
